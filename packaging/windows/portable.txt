Burin Docs portable mode

While this file sits next to pdfcraft.exe, Burin Docs keeps its settings, log files, crash-recovery
autosaves and new digital IDs in the Burin DocsData folder beside it, and writes nothing to
%APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move Burin Docs with its settings.

Delete this file to use the normal per-user folders (%APPDATA%\Burin Docs and
%LOCALAPPDATA%\Burin Docs) instead. If Burin DocsData can't be written (for example on a read-only
drive), Burin Docs says so and uses the per-user folders instead.
